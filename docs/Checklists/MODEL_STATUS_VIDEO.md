weights are staged, no download needed). Note the `TextEmbed` rank-3 fix (2026-07-01) also covers any
Wan-family text path fed a `CfgHelper.SliceBatchElement` (rank-3) encoder — Lance, Matrix-Game, WanS2V/Vace.
