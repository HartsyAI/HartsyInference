# Cleanup decisions worth preserving

Historical audit corrections, not a current dead-code inventory. Re-check call sites before acting; completed deletion/consolidation lists are in git. Remaining work is in [ROADMAP](ROADMAP.md).

TensorPool has no established production use; the old rationale that agent instructions require it was circular. Adopt or retire it based on evidence and public compatibility.

Owned F32 relabel copies and GGUF mmap reshape views have different dtype/ownership contracts. TensorCasts.RelabelRank2Copy is the shared copy helper; do not replace it with borrowed dictionary views.
