How to read these results

Warm request latency is measured after two unmeasured warmups (the first request is retained separately). Each case uses five fixed inputs in three independent worker processes. We take each session's median, then each machine's median, then the median across machines.

Repeated submissions from the same physical GPU and host do not receive additional weight. The interval is a deterministic 95% percentile bootstrap across machines; a single-machine result has no population interval. This is community evidence, not proof against fabricated measurements. Output review and independent reproduction are separate steps.

Driver, operating system, runtime, binary hashes, and settings form separate cohorts. CUDA and Vulkan are distinct. Raw first-token timing, decode throughput, first-request latency, all outputs, attempts and failures are retained in each evidence bundle. GPU memory measurements and reference-engine speed ratios are not currently reported.
