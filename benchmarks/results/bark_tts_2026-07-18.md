# Bark (Suno) TTS — perf pass, 2026-07-18

**RTF 15.53 → 2.30 (82.62 s → 12.23 s on a 5.32 s clip, 6.75×). Behavior-preserving: identical token
counts, output corr 1.0 on the fine-stage change, whisper word-perfect.**

Bark was the slowest remaining correct TTS model (~85–189 s/clip, unusably slow). Unlike Chatterbox — which
inherited the CosyVoice2 S3Gen residency speedup for free — Bark uses the shared GPT-2 `GptBackbone` +
EnCodec and shared none of that work, so it stayed host/AR-bound.

## Root cause
`GptBlock.ForwardStep` (the per-token decode called for every semantic + coarse AR step) ran the **entire
attention on the CPU host**: it read the fused-QKV projection back to the host every layer (24 device→host
syncs/step), kept the K/V cache in host `float[]`, and computed scores/softmax/weighted-V as nested host
loops over the growing prefix. The prefill already used GPU `ScaledDotProductAttention`, so only the decode
step was host-bound — an inconsistency, not a design necessity.

## Fix (mirrors the fast Chatterbox-T3 / `GenericTransformer` decode)
1. **Decode → GPU-resident.** Replaced the host `GptKvCache` (`float[]`) with the shared device-resident
   `FixedKvCache` (`KvCaches.ForDecode`). `GptBlock.ForwardCached` now handles prefill AND decode with all
   ops on the backend: `SliceLastDim` (split fused QKV) → `Permute0213` (to/from heads) → `AppendStep`
   (`KvCacheAppend`, K/V never leave the device) → `FlashAttention` (causal via `qOffset`, valid length
   passed explicitly). Zero `DataPointer` reads cross to the host mid-forward. `GptKvCache.cs` deleted.
2. **Coarse cache reuse.** Coarse's sliding-window re-prefill created a fresh cache per window (would leak
   device buffers); now one cache is `Reset()` per window.
3. **Fine stage → device glue.** The non-causal `GptBlock.Forward` (six full 1024-frame Bark-Fine passes)
   kept GPU `ScaledDotProductAttention` but replaced its host `SplitQkv` / `ReshapeTo/FromMultiHead4D` /
   `AddInto` glue with `SliceLastDim` / `Permute0213` / `backend.Add`. Math-preserving (A/B corr 1.000000).

**Zero new kernels** — pure reuse of existing backend ops (the session's recurring pattern).

## Correctness
- `Backbone_ForwardStep_MatchesFullSequenceForward` (CPU): incremental decode matches the full causal
  forward within 1e-4 (all 5 GptBackbone/Bark unit tests pass).
- Token counts unchanged pre/post migration (Semantic 266, Coarse 399) — the sampled stream is preserved.
- Whisper (medium.en) word-perfect on short + long clips.
- Fine-stage change: output waveform corr 1.000000 vs pre-change.

## Remaining lever (not pursued — diminishing returns, RTF already 6.75× better)
Coarse re-prefill: ~13 full ≤887-token prefills per clip. A carry-over cache across windows (keep the
overlapping history's K/V instead of recomputing) could cut this, but it complicates the exact upstream
window semantics for a fraction of the win already banked.
