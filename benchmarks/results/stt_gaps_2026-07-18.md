# STT gaps — Distil-Whisper / Whisper Streaming / Kyutai STT, 2026-07-18

Verified the three "installed but unverified" STT models on the whisper.cpp JFK clip (16 kHz, 11 s,
"…ask not what your country can do for you…"), RTX 3060.

## 1. Distil-Whisper ✅ (word-perfect)
`WhisperPipeline.LoadAsync("distil-whisper/distil-large-v3")` (`InferConfig` → `DistilLargeV3`, 32-enc/2-dec) →
`TranscribeWav`. **"And so, my fellow Americans, ask not what your country can do for you. Ask what you can do
for your country."** — RTF 0.44 (4.86 s / 11 s). No engine change; already wired.

## 2. Whisper Streaming ✅ (word-perfect, incremental)
`WhisperStreamingPipeline` (LocalAgreement stabilizer) wrapping whisper-small, fed in 0.5 s chunks. Confirms
text incrementally ("And so" → "my fellow" → "Americans, ask" → …) and the final transcript is verbatim. No
engine change.

## 3. Kyutai STT (kyutai/stt-1b-en_fr-trfs) ✅ (word-perfect — fully working)
The `-trfs` checkpoint was never actually loadable/correct end-to-end. Four real fixes landed:
- JFK: **"And so, my fellow Americans, ask not what your country can do for you. Ask what you can do for your
  country."** (143 frames → 54 tokens).
- Second clip: **"Hello there, this is Style TTS2, cloning a voice with the corrected male front end."**
  (ref "…MEL front end"; MEL→male is a pronunciation call, not an STT error).

- **Backbone `-trfs` layout converter** (`KyutaiSttModel.ReconcileHeliumLayout`): the checkpoint wraps each
  attention projection as `self_attn.{q,k,v,o}_proj.linear.weight` (extra `.linear`) and fuses the gated MLP as
  `mlp.fc1.weight [2·I, H]` (gate‖up) + `mlp.fc2.weight`. Rewritten to the standard
  `{q,k,v,o}_proj.weight` / `gate_proj|up_proj|down_proj.weight` the shared `GenericTransformer` reads. **Fixed
  a hard `KeyNotFoundException`** — the LM now loads.
- **Separate text head** (`KyutaiSttModel`): the checkpoint ships `lm_head.weight [8001, 2048]` distinct from the
  shared `embed_tokens` table (NOT tied); `ProjectText` now uses it. **Fixed garbage logits → sensible PAD-vs-word
  logits.**
- **Mimi ENCODER port** (`MimiSeanetEncoder` + `MimiSplitRvq.Encode` + `Mimi.Encode`): audio→codes was entirely
  unimplemented (only decode existed). Ported the SEANet encoder (mirror of the verified decoder), the strided
  downsample conv, the encoder transformer (reusing `MimiTransformer`), and nearest-neighbour residual VQ encode
  (semantic + acoustic input_proj). **VERIFIED word-perfect via an encode→decode round-trip** on the JFK clip
  (whisper: "And so my fellow Americans, ask not what your country can do for you…"). Reusable for any Mimi-encode
  consumer.

- **Delayed-streams frame alignment** (`KyutaiSttPipeline.Transcribe`) — the final fix. Per the HF reference
  (`prepare_inputs_for_generation`), the LM input is one position LONGER than the audio: **position 0 is a BOS
  frame** (every audio codebook = `audio_bos_token_id` 2048, text = `bos_token_id` 48000), and the audio is
  offset by **−1** (position `p` consumes audio frame `p−1`, from `positions - start - 1`). The predicted text
  token feeds the next position. Before this the model sat in an all-PAD fixed point (the audio wasn't driving
  the text stream); with it, the transcription is verbatim. The per-frame embedding (`text_row + Σ_k
  embed[vocab + k·codebook_vocab + code_k]`, summed) already matched the reference exactly.

**Perf note:** encode-bound (~11–12 s for the JFK clip). The nearest-neighbour RVQ encode is a host loop
(frames × 32 codebooks × 2048 vocab × 256 dim); the AR decode is a 16-layer Helium on GPU. Correct but not yet
real-time — a GPU RVQ-encode / decode-residency pass is the follow-up. Long audio (> `max_position_embeddings`
= 375 frames ≈ 30 s) needs the reference's windowed re-encode (not yet implemented).
