# Published fixture: f16-mat (R10)

`fixture.json` is the original R10 fixture manifest, byte for byte. Its SHA-256 is
`5439493c9d92847a3be8ae32dceb830e91c08e405f1bab3faaaecd3dea4b20a3`.

The manifest is stored with LF line endings. `.gitattributes` marks `benchmarks/attention/published-fixtures/**` as `-text`, so no
checkout converts its line endings and the SHA-256 above holds on every platform. A checkout made before that attribute existed
must be refreshed (`git checkout -- benchmarks/attention/published-fixtures`) before the hash is compared.

No tensor binaries are stored here. The manifest names `q.bin`, `k.bin` and `v.bin` and records their SHA-256 values. The original
tensors on the evidence machine match those values (checked 2026-11-16).

## What the manifest pins

- case_id `f16-mat`; route Dense; precision f16; `legacy_asserted_bounded` false; causal false; query_offset 0; scale 0.125 (dim 64).
- shapes: q `[1, 4, 256, 64]` F16; k and v `[1, 4, 516, 64]` F16.
- acceptance: source `docs/ATTENTION_CONTRACT.md` section 8; `rel_l2` 0.003; `mean_abs` null; `reviewed` false.
  These values are unchanged here. The reviewed flag stays false until the coordinator reviews the acceptance definition.
- generator: seed 1234, Python `random.Random`; the persisted bytes are authoritative.

## Generator identity and invocation

The original run did not log its generator invocation. The generator log recorded only the output path. The invocation below
reproduces this manifest byte for byte, and the three regenerated tensor files hash to the values the manifest records.
It was verified on 2026-11-16 by regenerating into an empty directory and comparing the results.

```python
import fixtures  # benchmarks/attention/fixtures.py
fixtures.create(root, 'f16-mat', batch=1, heads=4, kv_heads=4, sq=256, skv=516, dim=64,
                dtype='f16', seed=1234, precision='f16', route='Dense', kv_dtype='f16',
                causal=False, query_offset=0, legacy_asserted_bounded=False)
```

Run it from `benchmarks/attention`. `root` must not exist, because `create` refuses an existing directory.
